# Changelog

## 1.6.0 - 2026-08-16

- On desktop computers, the app now has a menu bar, with entries for help, for information about the app, and for quitting it. The menu button in the toolbar is no longer needed there.
- On Macs, the app now uses the translated app name in the application menu, in the Finder and in the Dock.
- On iPhones and iPads, the app now uses the translated app name on the home screen, and follows the language settings of the device.


## 1.5.0 - 2026-08-01

- The app now supports dark mode.
- Minor improvements in the user interface, updates in the underlying libraries.


## 1.4.11 - 2025-10-29

- Comply with the 16kb page size requirement on newer Android devices.


## 1.4.8 - 2025-07-02

- The app now targets Android API 35.


## 1.4.7 - 2025-01-14

- Reduce size by removing unused plugins from Android package.


## 1.4.6 - 2024-12-22

- Updates in the underlying libraries.


## 1.4.4 - 2024-07-27

- Minor improvements in the user interface, the app now targets Android API 34.
